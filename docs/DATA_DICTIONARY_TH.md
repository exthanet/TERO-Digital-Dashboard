# Data Dictionary (ภาษาไทย)

| ฟิลด์ | ความหมาย |
|---|---|
| Date | วันที่วัดผลหรือวันที่เผยแพร่ตามแหล่งข้อมูล |
| Program | รายการ เช่น ถกไม่เถียง, เงินทองของจริง |
| Topic | ชื่อประเด็นหรือชื่อคลิป |
| Platform | YouTube, Facebook, Instagram, TikTok หรือ TV |
| VDO_Type | Live, Full Episode, Highlight, Shorts, Reels หรือ TV |
| Views | ยอดวิว Digital; TV ใช้ Audience แยกต่างหาก |
| Engagement | Likes + Comments + Shares หรือค่าจากต้นทาง |
| TV_Rating_Total | Rating รวม |
| TV_Rating_15+BKK | Rating กลุ่ม BKK |
| TV_Rating_15+URBAN | Rating กลุ่ม Urban |
| TV_Rating_15+BKK&URBAN | Rating กลุ่ม BKK & Urban |
| TV_Rating_15+RURAL | Rating กลุ่ม Rural |

## Affiliate
Affiliate KPI ใช้ `Estimated revenue (THB)`, `Total sales (THB)` และ `Orders` จากแถว `Total` ส่วน Content/Product เป็น Top 500 จาก Source Export

สูตรหลัก: Commission Rate = Affiliate Revenue ÷ Total Sales; Average Order Value = Total Sales ÷ Orders; Revenue per Order = Affiliate Revenue ÷ Orders
